# 火柴人横版闯关 — 设计规格

日期：2026-07-18  
状态：已确认（待实现）

## 1. 背景与目标

在现有 Flutter 小游戏合集中新增「火柴人闯关」：横版平台跳跃 + 简单近战，首版 3 关递进。技术路线与扫雷 / 俄罗斯方块 / 羊了个羊一致：纯 Flutter（`CustomPainter` + `Timer` + `ChangeNotifierProvider`），不引入 Flame。

## 2. 范围

### 2.1 包含

- 首页入口、开始页选关（第 1/2/3 关均可直接进入）
- 虚拟摇杆移动 + 跳跃 + 近战攻击
- 平台、尖刺、短距左右巡逻小怪、终点旗帜
- HP、无敌帧、通关 / 失败 / 暂停
- 相机水平跟随玩家

### 2.2 不包含（首版）

- 道具、二段跳、远程武器、Boss
- 本地存档 / 关卡解锁进度
- 音效、网络、排行榜

接入：

- `lib/home/games.dart` 追加 `GameItem`

状态管理：必须使用 `ChangeNotifierProvider` + `ChangeNotifier`。

## 4. 玩法与核心规则

### 4.1 目标

操控火柴人从起点到达终点旗帜；可攻击小怪；接触尖刺或敌人身体掉血。

### 4.2 操作

| 控件 | 行为 |
|------|------|
| 左下虚拟摇杆 | 左右移动（水平分量 -1.0～1.0；上下忽略） |
| 右下「跳」 | 仅着地时可跳；无二段跳 |
| 右下「攻」 | 朝面朝方向短距近战；带短冷却 |

### 4.3 数值

- 玩家 HP：3
- 敌人 HP：1（一击消灭）
- 接触敌人身体 / 尖刺：扣 1 HP，约 1 秒无敌
- HP ≤ 0 → 失败；触达终点 → 通关
- 掉出地图底部 → 直接失败
- 敌人行为：在出生点左右短距巡逻（碰到巡逻边界折返）；无追击 AI

### 4.4 三关递进

| 关卡 | 侧重 |
|------|------|
| 第 1 关 | 短平台、少量尖刺、1–2 只怪，教学向 |
| 第 2 关 | 更碎平台、更多尖刺、3–4 只怪 |
| 第 3 关 | 更长关卡、更大间距、5+ 只怪 |

### 4.5 胜负后操作

结果弹层：重来 / 下一关（第 3 关通关则回选关）/ 返回选关。

## 5. 物理、碰撞与渲染

### 5.1 游戏循环

`Timer.periodic`（约 16ms）驱动：读输入 → 更新速度/位置 → 碰撞 → 战斗 → `notifyListeners`。  
`dispose` / 离开页面时必须停止 Timer。

### 5.2 物理

- 世界坐标，逻辑像素
- 恒定重力；着地时 `vy = 0`
- 水平速度由摇杆决定；松摇杆水平速度归零（避免幽灵滑动）

### 5.3 碰撞（AABB）

- 平台：脚底下落检测，落在顶面则着地
- 尖刺 / 敌人：相交且非无敌 → 扣血
- 攻击：玩家面前短矩形与敌人相交 → 移除敌人
- 终点：与旗帜区域相交 → 通关

### 5.4 关卡数据

`StickmanLevelBean` 用矩形列表描述平台 / 尖刺 / 敌人出生点 / 终点；三关为代码内静态配置，不引入 JSON 资源。

### 5.5 渲染

- `CustomPainter` 绘制背景条带、平台、尖刺、火柴人线稿、敌人、终点旗
- 相机水平跟随玩家，夹在关卡左右边界内
- 火柴人：头圆 + 躯干/四肢线条；攻击时手臂前挥一帧即可
- 无敌期间可短闪烁提示

## 6. 页面流程与边界

### 6.1 流程

1. 首页 → 火柴人闯关 → `StickmanPage`
2. 选关 → `StickmanGamePage(levelIndex)` → `startGame`
3. 暂停：停 Timer；继续 / 重开 / 回选关
4. 通关 / 失败：停物理，忽略输入，展示结果弹层

### 6.2 边界

- 攻击冷却中再次点击：忽略
- 通关 / 失败后忽略操作
- 关卡编号非法：回退第 1 关
- 首版不做音效与存档

## 7. 验收标准

- [ ] 首页可进入，三关均可开局
- [ ] 摇杆 / 跳 / 攻可用；能着地、能打死怪、踩刺掉血
- [ ] 到终点通关；掉坑或 HP 空失败
- [ ] 暂停与重开正常；离开页面无 Timer 泄漏
