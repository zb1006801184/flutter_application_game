# 火柴人横版闯关 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在小游戏合集中新增火柴人横版闯关（跑跳 + 近战 + 3 关），纯 Flutter 实现。

**Architecture:** `lib/stickman/` 模块；`StickmanNotifier`（ChangeNotifier + Timer ~16ms）驱动物理/碰撞/战斗；`CustomPainter` 渲染并相机跟随；虚拟摇杆 + 跳/攻控件。

**Tech Stack:** Flutter、flutter_riverpod（ChangeNotifierProvider.autoDispose）、go_router。不引入 Flame。按用户规则不新增测试文件。

**Spec:** `docs/superpowers/specs/2026-07-18-stickman-design.md`
